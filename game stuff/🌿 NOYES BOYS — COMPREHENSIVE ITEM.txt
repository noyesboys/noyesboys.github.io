🌿 NOYES BOYS — COMPREHENSIVE ITEM SYSTEM DESIGN
This is a brainstorm + implementation blueprint. Next prompt we code them all in.

IMPLEMENTATION ARCHITECTURE (how items plug into the game)
Item types I'm proposing:

consumable — one-use, applied to a plant or room
passive_room — placed in a room slot, always-on effect
passive_player — held in inventory, global effect
triggered — activates on a specific event (harvest, disease, etc.)
timed — effect lasts X real hours
equipment_upgrade — attaches to existing gear to modify it
genetic — affects breeding/seeds specifically
combo — only works when held alongside a partner item
cursed — has a downside AND an upside (risk/reward)

New inventory structure needed:
javascriptGS.itemInventory = {
  instances: [],  // { uid, itemId, qty, metadata, equippedRoomId, equippedPlantId }
  activeEffects: [] // { itemId, expiresAt, source }
}
Items live alongside the existing equipItems array but in their own dedicated itemInventory so they don't clash with wearable gear.
